# Final owner-only actions

Repository automation cannot perform these platform-controlled actions on behalf of the owner:

- satisfy current OpenAI/Anthropic age, identity, and developer-account verification;
- enter private reviewer credentials into platform submission portals;
- execute real ChatGPT/Claude authorization from the owner's interactive accounts when platform UI presence is required;
- accept current platform legal/submission terms;
- press the final public submission/release controls.

Everything else should be completed and documented before those actions.
