# Support requirements for public AI integrations

The public Gapwise support surface must remain usable without GitHub knowledge.

Minimum public support information:

- how to connect Gapwise to supported AI clients;
- how to enable/disable AI delegation;
- how to understand and change delegated read/write permissions;
- how to revoke connector access and reconnect;
- troubleshooting for failed OAuth, missing timetable data, stale writes, and unsupported academic mutations;
- privacy and terms links;
- a non-security support contact;
- a private security-reporting path;
- a statement that Gapwise is independent and not an official University of Toronto service.

The connector repository's GitHub Issues may be used for reproducible non-sensitive technical bugs, but users should never be told to place tokens, credentials, private timetable information, or vulnerability details in public issues.
