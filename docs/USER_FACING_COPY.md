# User-facing connector copy

**Gapwise for AI** lets a student connect their Gapwise timetable and campus context to a compatible AI assistant. The student chooses what Gapwise may share. The assistant can then ask Gapwise for source-backed schedule facts, realistic availability, deterministic gap assessments, and—only when explicitly permitted—bounded personal timetable changes.

Gapwise never gives AI permission to rewrite imported academic meetings. Users can revoke AI access from Gapwise.
