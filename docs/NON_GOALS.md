# Non-goals for the first production integration

- No LLM inference paid for or hosted by Gapwise.
- No provider-specific scheduling engine.
- No generic arbitrary-code/SQL/network tool.
- No friend data.
- No precise location.
- No raw `.ics` upload.
- No rewriting imported academic classes.
- No unattended destructive bulk actions.
- No public marketplace/directory submission before private validation.
- No weakening or replacement of Gapwise's existing encrypted private-cloud storage.
