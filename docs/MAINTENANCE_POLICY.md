# Connector maintenance policy

A material change to OAuth claims/audience handling, delegated-data schema, tool inputs/outputs, write semantics, public campus routing/gap semantics, or revocation behavior requires re-running affected unit/integration tests and the relevant named-client scenarios before the changed behavior is advertised as supported.

Directory listing copy must remain aligned with deployed behavior. Remove or narrow claims when a platform no longer supports a capability rather than weakening Gapwise security boundaries to preserve marketing language.
